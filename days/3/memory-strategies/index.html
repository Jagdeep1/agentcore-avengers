Memory Strategies

Raw conversation history is useful, but extracting meaningful insights is more powerful. Memory strategies determine what information gets extracted from conversations and how it’s stored for long-term retrieval.

Long-term Memory Architecture

Long-term memory extracts semantic meaning from conversations:

  • Extraction: AI analyzes conversations to identify key information
  • Storage: Extracted memories stored with vector embeddings
  • Retrieval: Semantic search finds relevant memories

Built-in Strategies

AgentCore Memory provides three built-in extraction strategies:

StrategyExtractsUse CaseExample
User PreferencePreferences, choices, stylesPersonalization”I prefer Python over JavaScript”
SemanticFacts, relationships, contextKnowledge base”Alex works at Acme Corp as a data engineer”
SummaryCondensed session overviewsQuick recall”User reported damaged order #12345, refund processed”

Strategy Namespaces

Each strategy stores memories in a specific namespace pattern:

  • User Preferences: /preferences/{actorId} (per user)
  • Semantic: /facts/{actorId} (per user)
  • Summary: /summaries/{actorId}/{sessionId} (per session)

Namespaces keep different memory types organized and searchable.

Step 1: Configure Multiple Strategies

Create a memory resource with all three built-in strategies.

Create configure_strategies.py:

#!/usr/bin/env python3
from bedrock_agentcore.memory import MemoryClient

REGION = "us-east-1"
MEMORY_NAME = "Day3StrategiesMemory"

def main():
    print("=" * 70)
    print("Configuring Memory with Multiple Strategies")
    print("=" * 70)

    try:
        print(f"\n1. Initializing MemoryClient for region: {REGION}")
        memory_client = MemoryClient(region_name=REGION)

        print(f"\n2. Creating memory: '{MEMORY_NAME}' with 3 strategies")
        print("   Strategy 1: User Preferences")
        print("   Strategy 2: Semantic Facts")
        print("   Strategy 3: Session Summaries")
        print("\n   This will take 2-3 minutes...")

        strategies = [
            {
                "userPreferenceMemoryStrategy": {
                    "name": "PreferenceLearner",
                    "namespaces": ["/preferences/{actorId}"]
                }
            },
            {
                "semanticMemoryStrategy": {
                    "name": "FactExtractor",
                    "namespaces": ["/facts/{actorId}"]
                }
            },
            {
                "summaryMemoryStrategy": {
                    "name": "SessionSummarizer",
                    "namespaces": ["/summaries/{actorId}/{sessionId}"]
                }
            }
        ]

        memory = memory_client.create_memory_and_wait(
            name=MEMORY_NAME,
            description="Memory with user preferences, semantic facts, and summaries",
            strategies=strategies
        )

        print("\n" + "=" * 70)
        print("✓ Memory Created Successfully!")
        print("=" * 70)
        print(f"Memory ID: {memory.get('id')}")
        print(f"Status: {memory.get('status')}")

        with open('memory_id.txt', 'w') as f:
            f.write(memory.get('id'))
        print("\n✓ Memory ID saved to 'memory_id.txt'")

    except Exception as e:
        print(f"\n✗ Error: {str(e)}")
        return 1

    return 0

if __name__ == "__main__":
    exit(main())

Step 2: Test User Preference Strategy

The User Preference strategy identifies and stores user preferences, choices, and styles.

Create test_user_preference.py:

#!/usr/bin/env python3
import time
from datetime import datetime
from strands import Agent
from strands.models import BedrockModel
from bedrock_agentcore.memory.integrations.strands.config import AgentCoreMemoryConfig
from bedrock_agentcore.memory.integrations.strands.session_manager import AgentCoreMemorySessionManager
from bedrock_agentcore.memory.session import MemorySessionManager

REGION = "us-east-1"
MODEL_ID = "us.anthropic.claude-3-5-sonnet-20241022-v2:0"

def main():
    # Load memory ID
    with open('memory_id.txt', 'r') as f:
        memory_id = f.read().strip()

    # Create session
    timestamp = datetime.now().strftime("%Y%m%d%H%M%S")
    actor_id = f"user_pref_{timestamp}"
    session_id = f"session_pref_{timestamp}"

    # Create agent with memory
    config = AgentCoreMemoryConfig(
        memory_id=memory_id,
        session_id=session_id,
        actor_id=actor_id
    )

    session_manager = AgentCoreMemorySessionManager(
        agentcore_memory_config=config,
        region_name=REGION
    )

    model = BedrockModel(model_id=MODEL_ID, region_name=REGION)
    agent = Agent(model=model, session_manager=session_manager)

    # Express preferences
    print("Expressing user preferences...")
    agent("I always prefer Python over JavaScript for backend work.")
    agent("I like using VS Code as my primary editor.")
    agent("I prefer working on algorithmic problems rather than UI work.")

    # Wait for extraction
    print("\nWaiting 90 seconds for preference extraction...")
    time.sleep(90)

    # Query preferences
    session_mgr = MemorySessionManager(memory_id=memory_id, region_name=REGION)
    session = session_mgr.create_memory_session(actor_id=actor_id, session_id=session_id)

    preferences = session.list_long_term_memory_records(namespace_prefix="/preferences/")

    print("\n✓ Extracted Preferences:")
    for i, pref in enumerate(preferences, 1):
        content = pref.get('content', {})
        if isinstance(content, dict):
            print(f"  {i}. {content.get('text', '')}")

    return 0

if __name__ == "__main__":
    exit(main())

What Makes a Preference?

User Preference strategy looks for:

  • Explicit statements: “I prefer X over Y”
  • Likes/dislikes: “I like/dislike X”
  • Usage patterns: “I always use X”
  • Styles: “I prefer X approach”

These are stored separately from facts to enable preference-based personalization.

What just happened:

  • ✓ Agent conversation contained preference statements
  • ✓ User Preference strategy extracted 3 preferences
  • ✓ Preferences stored in /preferences/{actorId} namespace
  • ✓ Each preference is a distinct, searchable record

Step 3: Test Semantic Strategy

The Semantic strategy extracts factual information, relationships, and context.

Create test_semantic.py:

#!/usr/bin/env python3
import time
from datetime import datetime
from strands import Agent
from strands.models import BedrockModel
from bedrock_agentcore.memory.integrations.strands.config import AgentCoreMemoryConfig
from bedrock_agentcore.memory.integrations.strands.session_manager import AgentCoreMemorySessionManager
from bedrock_agentcore.memory.session import MemorySessionManager

REGION = "us-east-1"
MODEL_ID = "us.anthropic.claude-3-5-sonnet-20241022-v2:0"

def main():
    # Load memory and create session
    with open('memory_id.txt', 'r') as f:
        memory_id = f.read().strip()

    timestamp = datetime.now().strftime("%Y%m%d%H%M%S")
    actor_id = f"user_semantic_{timestamp}"
    session_id = f"session_semantic_{timestamp}"

    # Create agent
    config = AgentCoreMemoryConfig(memory_id=memory_id, session_id=session_id, actor_id=actor_id)
    session_manager = AgentCoreMemorySessionManager(agentcore_memory_config=config, region_name=REGION)
    model = BedrockModel(model_id=MODEL_ID, region_name=REGION)
    agent = Agent(model=model, session_manager=session_manager)

    # Share factual information
    print("Sharing factual information...")
    agent("I work at Acme Corporation as a Senior Data Engineer.")
    agent("I'm working on a machine learning pipeline for customer analytics.")
    agent("The project deadline is March 15, 2026.")
    agent("We're using Apache Spark, Delta Lake, and MLflow.")

    # Wait for extraction
    print("\nWaiting 90 seconds for fact extraction...")
    time.sleep(90)

    # Query facts
    session_mgr = MemorySessionManager(memory_id=memory_id, region_name=REGION)
    session = session_mgr.create_memory_session(actor_id=actor_id, session_id=session_id)

    facts = session.list_long_term_memory_records(namespace_prefix="/facts/")

    print("\n✓ Extracted Facts:")
    for i, fact in enumerate(facts, 1):
        content = fact.get('content', {})
        if isinstance(content, dict):
            print(f"  {i}. {content.get('text', '')}")

    # Semantic search
    results = session.search_long_term_memories(
        query="What is the user's job and project?",
        namespace_prefix="/facts/",
        top_k=3
    )

    print("\n✓ Semantic Search Results:")
    for i, result in enumerate(results, 1):
        content = result.get('content', {})
        if isinstance(content, dict):
            print(f"  {i}. {content.get('text', '')}")

    return 0

if __name__ == "__main__":
    exit(main())

Facts vs Preferences

Semantic (Facts): Objective statements about the world

  • “Alex works at Acme Corp”
  • “The deadline is March 15”
  • “We use Apache Spark”

User Preferences: Subjective likes/dislikes

  • “I prefer Python”
  • “I like VS Code”

Semantic strategy focuses on verifiable information, not opinions.

What just happened:

  • ✓ Shared multiple factual statements
  • ✓ Semantic strategy extracted 6 discrete facts
  • ✓ Facts stored in /facts/{actorId} namespace
  • ✓ Semantic search ranked facts by relevance to query

Step 4: Test Summary Strategy

The Summary strategy creates condensed overviews of entire sessions.

Create test_summary.py:

#!/usr/bin/env python3
import time
from datetime import datetime
from strands import Agent
from strands.models import BedrockModel
from bedrock_agentcore.memory.integrations.strands.config import AgentCoreMemoryConfig
from bedrock_agentcore.memory.integrations.strands.session_manager import AgentCoreMemorySessionManager
from bedrock_agentcore.memory.session import MemorySessionManager

REGION = "us-east-1"
MODEL_ID = "us.anthropic.claude-3-5-sonnet-20241022-v2:0"

def main():
    # Load memory and create session
    with open('memory_id.txt', 'r') as f:
        memory_id = f.read().strip()

    timestamp = datetime.now().strftime("%Y%m%d%H%M%S")
    actor_id = f"user_summary_{timestamp}"
    session_id = f"session_summary_{timestamp}"

    # Create agent
    config = AgentCoreMemoryConfig(memory_id=memory_id, session_id=session_id, actor_id=actor_id)
    session_manager = AgentCoreMemorySessionManager(agentcore_memory_config=config, region_name=REGION)
    model = BedrockModel(model_id=MODEL_ID, region_name=REGION)
    agent = Agent(model=model, system_prompt="You are a customer support assistant.", session_manager=session_manager)

    # Simulate multi-turn support conversation
    print("Simulating customer support conversation...")
    conversations = [
        "Hi, I placed an order last week but it hasn't arrived. Order #98765.",
        "I ordered it on January 10th. Supposed to arrive by January 17th.",
        "Tracking shows it's stuck in Memphis since January 14th.",
        "I'd like a refund. It was a birthday gift and now it's too late.",
        "My email is customer@example.com and phone is 555-0123.",
        "When will I receive the refund?",
        "Please send me a confirmation email."
    ]

    for msg in conversations:
        agent(msg)
        time.sleep(1)

    # Wait for summary
    print("\nWaiting 90 seconds for session summary...")
    time.sleep(90)

    # Query summary
    session_mgr = MemorySessionManager(memory_id=memory_id, region_name=REGION)
    session = session_mgr.create_memory_session(actor_id=actor_id, session_id=session_id)

    summaries = session.list_long_term_memory_records(
        namespace_prefix=f"/summaries/{actor_id}/{session_id}"
    )

    print("\n✓ Extracted Session Summary:")
    for summary in summaries:
        content = summary.get('content', {})
        if isinstance(content, dict):
            print(f"\n{content.get('text', '')}")

    return 0

if __name__ == "__main__":
    exit(main())

7-turn conversation → 2-sentence summary

Perfect for:

  • Quick context recall (“What was this session about?”)
  • Cross-session learning (“How do I usually handle refunds?”)
  • Reducing LLM context load

Summaries capture outcomes without conversational noise.

  • ✓ Summary stored in /summaries/{actorId}/{sessionId} namespace
  • ✓ Captures issue, resolution, and key details

Step 5: Memory Branching (Optional)

Memory branching uses the fork_conversation() API to create parallel conversation paths that inherit context from a parent branch but evolve independently.

Create memory_branching.py:

#!/usr/bin/env python3
from datetime import datetime
from bedrock_agentcore.memory import MemorySessionManager
from bedrock_agentcore.memory.constants import ConversationalMessage, MessageRole

REGION = "us-east-1"

def main():
    with open('memory_id.txt', 'r') as f:
        memory_id = f.read().strip()

    timestamp = datetime.now().strftime("%Y%m%d%H%M%S")
    actor_id = f"user_branch_{timestamp}"
    session_id = f"session_branch_{timestamp}"

    # Initialize memory session
    memory_manager = MemorySessionManager(memory_id=memory_id, region_name=REGION)
    memory_session = memory_manager.create_memory_session(actor_id=actor_id, session_id=session_id)

    # Main conversation on "main" branch (default)
    print("Creating main conversation...")
    memory_session.add_turns(
        messages=[ConversationalMessage("I'm considering switching from Java to Python.", MessageRole.USER)]
    )
    memory_session.add_turns(
        messages=[ConversationalMessage("Tell me about your Java experience?", MessageRole.ASSISTANT)]
    )
    memory_session.add_turns(
        messages=[ConversationalMessage("5 years in enterprise applications.", MessageRole.USER)]
    )
    memory_session.add_turns(
        messages=[ConversationalMessage("That's substantial experience!", MessageRole.ASSISTANT)]
    )

    # Get last event from main branch to fork from
    main_events = memory_session.list_events(branch_name="main")
    last_event_id = main_events[-1].eventId

    # Fork branch 1: Java path
    print("\nForking 'java_path' branch...")
    memory_session.fork_conversation(
        root_event_id=last_event_id,
        branch_name="java_path",
        messages=[
            ConversationalMessage("What if I stay with Java and specialize in microservices?", MessageRole.USER),
            ConversationalMessage("Great path! Focus on Spring Boot and Kubernetes.", MessageRole.ASSISTANT)
        ]
    )

    # Fork branch 2: Python path
    print("Forking 'python_path' branch...")
    memory_session.fork_conversation(
        root_event_id=last_event_id,
        branch_name="python_path",
        messages=[
            ConversationalMessage("What if I switch to Python for ML/data science?", MessageRole.USER),
            ConversationalMessage("Strong choice! Learn pandas and TensorFlow.", MessageRole.ASSISTANT)
        ]
    )

    # List all branches
    branches = memory_session.list_branches()
    print(f"\n✓ Created {len(branches)} branches:")
    for branch in branches:
        events = memory_session.list_events(branch_name=branch.name)
        print(f"  • {branch.name}: {len(events)} events")

    print("\nMemory Branching Benefits:")
    print("  • Branches inherit parent context up to fork point")
    print("  • Each branch evolves independently after forking")
    print("  • Explore 'what-if' scenarios without polluting main conversation")

    return 0

if __name__ == "__main__":
    exit(main())

Run the script:

python memory_branching.py

Key API - fork_conversation():

memory_session.fork_conversation(
    root_event_id="event_to_fork_from",  # Event ID from parent branch
    branch_name="new_branch_name",       # Name for the new branch
    messages=[...]                        # Initial messages for the branch
)

What branching enables:

  • ✓ Branches inherit conversation history from parent
  • ✓ Independent evolution after fork point
  • ✓ Explore multiple scenarios without affecting main context
  • ✓ Use cases: A/B testing, what-if scenarios, specialized workflows

Cleanup

Delete the memory resource when done testing.

Create cleanup_strategies.py:

#!/usr/bin/env python3
from bedrock_agentcore.memory import MemoryClient

REGION = "us-east-1"

def main():
    with open('memory_id.txt', 'r') as f:
        memory_id = f.read().strip()

    memory_client = MemoryClient(region_name=REGION)
    memory_client.delete_memory(memory_id=memory_id)

    print("✓ Memory deleted successfully!")

    import os
    for f in ['memory_id.txt', 'pref_session_info.txt',
              'semantic_session_info.txt', 'summary_session_info.txt',
              'branch_session_info.txt']:
        if os.path.exists(f):
            os.remove(f)

    return 0

if __name__ == "__main__":
    exit(main())

Run the script:

python cleanup_strategies.py

When to Use Each Strategy

Use all three for comprehensive agent memory:

  • Preferences: Tailor responses to user’s likes/dislikes
  • Semantic: Build knowledge base of facts and relationships
  • Summary: Quick context loading for returning users

They complement each other - same input, different extracted insights!
