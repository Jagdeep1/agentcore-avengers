Memory Basics

Remember Day 1? Your agent forgot everything between requests. That’s because AI models are inherently stateless - each request starts fresh with no knowledge of previous interactions.

AgentCore Memory solves this by providing managed memory services that persist context across interactions.

AgentCore Memory Architecture

AgentCore Memory provides two complementary memory systems:

  • Short-term memory: Raw conversation events for immediate context
  • Long-term memory: Semantic extraction and consolidation for persistent knowledge

Short-term Memory Architecture

Short-term memory stores raw conversation events:

  • Recent message retrieval with get_last_k_turns()
  • Event creation with create_event()
  • Session-based conversation tracking
FeatureShort-term MemoryLong-term Memory
ScopeSingle sessionAcross all sessions
DurationSession lifetimePersistent
ContentRaw conversation turnsExtracted insights

When to Use Each

Short-term: For immediate context like “what did I just ask?”

Long-term: For persistent knowledge like “what are my preferences?”

Step 1: Create a Memory Resource

We’ll create an AgentCore Memory with a semantic strategy. Semantic strategy automatically extracts facts and insights from conversations for long-term storage.

Create create_memory.py:

#!/usr/bin/env python3
"""
create_memory.py - Create an AgentCore Memory with semantic strategy

This script creates a memory resource with both short-term and long-term memory
capabilities using a semantic strategy.
"""

from bedrock_agentcore_starter_toolkit.operations.memory.manager import MemoryManager
from bedrock_agentcore_starter_toolkit.operations.memory.models.strategies import SemanticStrategy

# Configuration
REGION = "us-east-1"  # Change this to your preferred region
MEMORY_NAME = "Day3AgentMemory"

def main():
    """Create memory resource with semantic strategy."""
    print("=" * 70)
    print("Creating AgentCore Memory Resource")
    print("=" * 70)

    try:
        # Initialize memory manager
        print(f"\n1. Initializing MemoryManager for region: {REGION}")
        memory_manager = MemoryManager(region_name=REGION)

        # Create memory with semantic strategy
        print(f"\n2. Creating memory: '{MEMORY_NAME}'")
        print("   - Enabling short-term memory (conversation history)")
        print("   - Enabling long-term memory (semantic extraction)")
        print("\n   This will take 2-3 minutes to become ACTIVE...")

        memory = memory_manager.get_or_create_memory(
            name=MEMORY_NAME,
            description="Day 3 agent memory with semantic strategy",
            strategies=[
                SemanticStrategy(
                    name="semanticLongTermMemory",
                    namespaces=['/strategies/{memoryStrategyId}/actors/{actorId}'],
                )
            ]
        )

        # Display results
        print("\n" + "=" * 70)
        print("✓ Memory Created Successfully!")
        print("=" * 70)
        print(f"Memory ID: {memory.get('id')}")
        print(f"Memory Name: {memory.get('name')}")
        print(f"Status: {memory.get('status')}")
        print(f"Description: {memory.get('description')}")

        # Save memory ID to file for other scripts
        with open('memory_id.txt', 'w') as f:
            f.write(memory.get('id'))
        print("\n✓ Memory ID saved to 'memory_id.txt'")

        print("\n" + "=" * 70)
        print("Next Steps:")
        print("=" * 70)
        print("1. Wait for memory status to become ACTIVE (~2-3 minutes)")
        print("2. Run integrate_memory.py to connect this memory to an agent")
        print("=" * 70)

    except Exception as e:
        print(f"\n✗ Error creating memory: {str(e)}")
        print("\nTroubleshooting:")
        print("- Verify AWS credentials are configured (aws configure)")
        print("- Ensure you have permissions for bedrock-agentcore:CreateMemory")
        print(f"- Check that AgentCore Memory is available in {REGION}")
        return 1

    return 0

if __name__ == "__main__":
    exit(main())

Understanding Memory Strategies

A memory strategy defines how conversations are processed into long-term memories:

  • Semantic Strategy: Extracts factual information (e.g., “The user works with Python”)
  • User Preference Strategy: Identifies preferences (e.g., “The user prefers TypeScript”)
  • Summary Strategy: Creates condensed session summaries

We’re starting with semantic strategy - the most versatile option for general knowledge extraction.

What just happened:

  • ✓ Created an AgentCore Memory resource with semantic extraction
  • ✓ Memory is now ACTIVE and ready to store conversations
  • ✓ Semantic strategy will automatically extract facts from conversations
  • ✓ Memory ID saved locally for use in subsequent steps

Step 2: Integrate Memory with a Strands Agent

Now we’ll create a Strands agent that automatically saves and retrieves memories using the AgentCoreMemorySessionManager.

Create integrate_memory.py:

#!/usr/bin/env python3
"""
integrate_memory.py - Integrate AgentCore Memory with a Strands Agent

This script demonstrates how to connect an AgentCore Memory to a Strands agent
using the AgentCoreMemorySessionManager.
"""

from datetime import datetime
from strands import Agent
from strands.models import BedrockModel
from bedrock_agentcore.memory.integrations.strands.config import AgentCoreMemoryConfig
from bedrock_agentcore.memory.integrations.strands.session_manager import AgentCoreMemorySessionManager

# Configuration
REGION = "us-east-1"
MODEL_ID = "us.anthropic.claude-3-5-sonnet-20241022-v2:0"

def main():
    """Create a Strands agent with AgentCore Memory integration."""
    print("=" * 70)
    print("Integrating AgentCore Memory with Strands Agent")
    print("=" * 70)

    try:
        # Load memory ID from file
        print("\n1. Loading memory ID from memory_id.txt...")
        with open('memory_id.txt', 'r') as f:
            memory_id = f.read().strip()
        print(f"   Memory ID: {memory_id}")

        # Create unique actor and session IDs
        timestamp = datetime.now().strftime("%Y%m%d%H%M%S")
        actor_id = f"user_{timestamp}"
        session_id = f"session_{timestamp}"

        print(f"\n2. Creating session identifiers:")
        print(f"   Actor ID: {actor_id}")
        print(f"   Session ID: {session_id}")

        # Configure memory
        print(f"\n3. Configuring AgentCore Memory...")
        agentcore_memory_config = AgentCoreMemoryConfig(
            memory_id=memory_id,
            session_id=session_id,
            actor_id=actor_id
        )

        # Create session manager
        print(f"   Creating memory session manager for region: {REGION}")
        session_manager = AgentCoreMemorySessionManager(
            agentcore_memory_config=agentcore_memory_config,
            region_name=REGION
        )

        # Create Bedrock model
        print(f"\n4. Initializing Bedrock model: {MODEL_ID}")
        model = BedrockModel(
            model_id=MODEL_ID,
            region_name=REGION
        )

        # Create agent with memory
        print(f"\n5. Creating Strands agent with memory integration...")
        agent = Agent(
            model=model,
            system_prompt=(
                "You are a helpful assistant with memory capabilities. "
                "You can remember information from past conversations and use it "
                "to provide personalized responses. Always acknowledge when you "
                "remember something from a previous interaction."
            ),
            session_manager=session_manager,
        )

        print("\n" + "=" * 70)
        print("✓ Agent Created Successfully with Memory!")
        print("=" * 70)

        # Test the agent with a simple conversation
        print("\n6. Testing agent with memory...")
        print("\n" + "-" * 70)

        user_input_1 = "Hi! My name is Alex and I work as a software engineer."
        print(f"User: {user_input_1}")
        response_1 = agent(user_input_1)
        print(f"Agent: {response_1}")

        print("\n" + "-" * 70)

        user_input_2 = "I really enjoy working with Python and AWS."
        print(f"User: {user_input_2}")
        response_2 = agent(user_input_2)
        print(f"Agent: {response_2}")

        print("\n" + "-" * 70)

        user_input_3 = "What do you know about me?"
        print(f"User: {user_input_3}")
        response_3 = agent(user_input_3)
        print(f"Agent: {response_3}")

        print("\n" + "-" * 70)

        print("\n" + "=" * 70)
        print("What just happened:")
        print("=" * 70)
        print("✓ Memory resource loaded from memory_id.txt")
        print("✓ Session manager configured with unique actor/session IDs")
        print("✓ Strands agent created with automatic memory integration")
        print("✓ Agent conversation history automatically saved to memory")
        print("✓ Agent can recall information from the conversation")
        print("\n  Note: Short-term memory is working immediately.")
        print("  Long-term memory extraction will happen in the background.")
        print("=" * 70)

        # Save session info for test script
        with open('session_info.txt', 'w') as f:
            f.write(f"{memory_id}\n{actor_id}\n{session_id}\n")
        print("\n✓ Session info saved to 'session_info.txt' for testing")

        print("\n" + "=" * 70)
        print("Next Steps:")
        print("=" * 70)
        print("1. Wait 60-90 seconds for long-term memory extraction")
        print("2. Run test_memory.py to query short-term and long-term memories")
        print("=" * 70)

    except FileNotFoundError:
        print("\n✗ Error: memory_id.txt not found")
        print("\nPlease run create_memory.py first to create a memory resource.")
        return 1
    except Exception as e:
        print(f"\n✗ Error: {str(e)}")
        print("\nTroubleshooting:")
        print("- Verify AWS credentials are configured")
        print("- Ensure memory resource exists and is ACTIVE")
        print(f"- Check model access for {MODEL_ID}")
        print(f"- Verify AgentCore Memory is available in {REGION}")
        return 1

    return 0

if __name__ == "__main__":
    exit(main())

Step 3: Test Memory Retrieval

Wait 60-90 seconds for the background long-term memory extraction to complete, then run this script to query both short-term and long-term memories.

Create test_memory.py:

#!/usr/bin/env python3
"""
test_memory.py - Test short-term and long-term memory retrieval

This script demonstrates querying both short-term memory (conversation history)
and long-term memory (extracted facts and insights).
"""

from bedrock_agentcore.memory.session import MemorySessionManager

# Configuration
REGION = "us-east-1"

def main():
    """Test memory retrieval from AgentCore Memory."""
    print("=" * 70)
    print("Testing AgentCore Memory - Short-term and Long-term")
    print("=" * 70)

    try:
        # Load session info from file
        print("\n1. Loading session info from session_info.txt...")
        with open('session_info.txt', 'r') as f:
            lines = f.read().strip().split('\n')
            memory_id = lines[0]
            actor_id = lines[1]
            session_id = lines[2]

        print(f"   Memory ID: {memory_id}")
        print(f"   Actor ID: {actor_id}")
        print(f"   Session ID: {session_id}")

        # Create session manager
        print(f"\n2. Creating MemorySessionManager for region: {REGION}")
        session_manager = MemorySessionManager(
            memory_id=memory_id,
            region_name=REGION
        )

        session = session_manager.create_memory_session(
            actor_id=actor_id,
            session_id=session_id
        )

        # Test short-term memory
        print("\n" + "=" * 70)
        print("SHORT-TERM MEMORY (Conversation History)")
        print("=" * 70)

        print("\n3. Retrieving last 10 conversation turns...")
        turns = session.get_last_k_turns(k=10)

        if turns:
            print(f"\n   Found {len(turns)} turns in short-term memory")
            print("   (Showing first turn as example)")
            # Note: Turns are stored in internal format, showing count is sufficient
        else:
            print("   No conversation turns found in short-term memory.")

        # Test long-term memory
        print("\n" + "=" * 70)
        print("LONG-TERM MEMORY (Extracted Insights)")
        print("=" * 70)

        print("\n4. Checking if long-term memories have been extracted...")
        print("   (This may take 60-90 seconds after conversation)")

        # Try to list long-term memories
        print("\n5. Listing all long-term memory records...")
        try:
            memory_records = session.list_long_term_memory_records(
                namespace_prefix="/"
            )

            if memory_records:
                print(f"\n   Found {len(memory_records)} long-term memory record(s):")
                for i, record in enumerate(memory_records, 1):
                    print(f"\n   Record {i}:")
                    content = record.get('content', {})
                    if isinstance(content, dict):
                        text = content.get('text', '')
                        print(f"   Content: {text}")
                    print("   " + "-" * 66)
            else:
                print("\n   ⏳ No long-term memories extracted yet.")
                print("\n   This is normal if less than 60-90 seconds have passed.")
                print("   Long-term memory extraction happens asynchronously.")

        except Exception as e:
            print(f"\n   ⏳ Long-term memory not yet available: {str(e)}")

        # Try semantic search
        print("\n6. Performing semantic search on long-term memories...")
        try:
            search_results = session.search_long_term_memories(
                query="What are the user's technical skills and preferences?",
                namespace_prefix="/",
                top_k=3
            )

            if search_results:
                print(f"\n   Found {len(search_results)} relevant memories:")
                for i, record in enumerate(search_results, 1):
                    content = record.get('content', {})
                    if isinstance(content, dict):
                        text = content.get('text', '')
                        print(f"\n   Result {i}: {text}")
            else:
                print("\n   ⏳ No searchable long-term memories yet.")

        except Exception as e:
            print(f"\n   ⏳ Semantic search not yet available")

        # Summary
        print("\n" + "=" * 70)
        print("What just happened:")
        print("=" * 70)
        print("✓ Retrieved short-term memory (conversation history)")
        print("✓ Checked for long-term memory records (facts extraction)")
        print("✓ Attempted semantic search on long-term memories")
        print("\n  Short-term memory: Available immediately after conversation")
        print("  Long-term memory: Extracted asynchronously (60-90 seconds)")
        print("=" * 70)

        print("\n" + "=" * 70)
        print("Next Steps:")
        print("=" * 70)
        print("1. If long-term memories aren't showing yet, wait and run again")
        print("2. Run cleanup_memory.py to delete the memory resource")
        print("=" * 70)

    except FileNotFoundError:
        print("\n✗ Error: session_info.txt not found")
        print("\nPlease run integrate_memory.py first to create a session.")
        return 1
    except Exception as e:
        print(f"\n✗ Error: {str(e)}")
        print("\nTroubleshooting:")
        print("- Verify AWS credentials are configured")
        print("- Ensure memory resource exists and is ACTIVE")
        print(f"- Verify AgentCore Memory is available in {REGION}")
        return 1

    return 0

if __name__ == "__main__":

Understanding Memory Extraction

Short-term memory stores raw conversation turns and is available immediately.

Long-term memory extraction happens asynchronously:

  1. Conversation events are written to memory
  2. Background process analyzes the events (~60-90 seconds)
  3. Semantic strategy extracts key facts and insights
  4. Facts are stored as searchable memory records

The search_long_term_memories() function uses semantic search to find the most relevant memories for a given query.

  • ✓ Verified both memory systems are working correctly

Step 4: Cleanup

When you’re done testing, delete the memory resource to avoid ongoing charges.

Create cleanup_memory.py:

#!/usr/bin/env python3
"""
cleanup_memory.py - Delete AgentCore Memory resource

This script deletes the memory resource to clean up after testing.
"""

from bedrock_agentcore_starter_toolkit.operations.memory.manager import MemoryManager

# Configuration
REGION = "us-east-1"

def main():
    """Delete the AgentCore Memory resource."""
    print("=" * 70)
    print("Cleaning up AgentCore Memory Resource")
    print("=" * 70)

    try:
        # Load memory ID from file
        print("\n1. Loading memory ID from memory_id.txt...")
        with open('memory_id.txt', 'r') as f:
            memory_id = f.read().strip()
        print(f"   Memory ID: {memory_id}")

        # Initialize memory manager
        print(f"\n2. Initializing MemoryManager for region: {REGION}")
        memory_manager = MemoryManager(region_name=REGION)

        # Delete memory
        print(f"\n3. Deleting memory resource...")
        memory_manager.delete_memory(memory_id=memory_id)

        print("\n" + "=" * 70)
        print("✓ Memory Resource Deleted Successfully!")
        print("=" * 70)

        # Clean up local files
        print("\n4. Cleaning up local files...")
        import os
        if os.path.exists('memory_id.txt'):
            os.remove('memory_id.txt')
            print("   ✓ Removed memory_id.txt")
        if os.path.exists('session_info.txt'):
            os.remove('session_info.txt')
            print("   ✓ Removed session_info.txt")

        print("\n" + "=" * 70)
        print("Cleanup Complete!")
        print("=" * 70)

    except FileNotFoundError:
        print("\n✗ Error: memory_id.txt not found")
        print("\nMemory may have already been deleted.")
        return 1
    except Exception as e:
        print(f"\n✗ Error: {str(e)}")
        return 1

    return 0

if __name__ == "__main__":
    exit(main())

Memory API Reference

Core Memory Operations

from bedrock_agentcore.memory import MemoryClient

memory_client = MemoryClient(region_name='us-east-1')

# Create a memory resource
memory = memory_client.create_memory(
    name='my-memory',
    description='Memory for my agent',
    strategies=[{
        "semanticMemoryStrategy": {
            "name": "Facts",
            "namespaces": ["/facts/{actorId}"]
        }
    }]
)

# Create conversation events
memory_client.create_event(
    memory_id=memory['id'],
    actor_id='user-123',
    session_id='session-456',
    messages=[
        ("Hello, I need help with Python", "USER"),
        ("I'd be happy to help! What do you need?", "ASSISTANT")
    ]
)

# Retrieve memories
memories = memory_client.retrieve_memories(
    memory_id=memory['id'],
    namespace='/facts/user-123',
    query='What are my preferences?',
    top_k=5
)

# Delete memory
memory_client.delete_memory(memory_id=memory['id'])
