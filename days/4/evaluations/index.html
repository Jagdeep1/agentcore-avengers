Agent Evaluations

AgentCore Evaluations provides systematic measurement of agent performance through built-in and custom evaluators. Evaluations use LLM-as-a-judge patterns to analyze agent traces and provide actionable quality metrics.

Prerequisites

Before starting this module, ensure you have:

  1. Deployed agent from observability module - The agent must be in READY state with traces in CloudWatch
  2. Dependencies installed - Run pip install bedrock-agentcore-starter-toolkit boto3 pyyaml
  3. AWS credentials configured - With permissions for AgentCore Evaluations

Reusing the Observable Agent

This module uses the agent deployed in the Observability module. If you haven’t completed that module, do so first.

Evaluation Architecture

AgentCore provides multiple interfaces for evaluations:

  • boto3 SDK - Full control over evaluation APIs
  • AgentCore Starter Toolkit - Simplified abstractions for common workflows

Metrics Per Level

Evaluations operate at three levels of agent interaction:

LevelScopeBuilt-in Evaluators
SessionComplete conversation across multiple turnsGoal Success Rate
TraceIndividual request/response pairCorrectness
SpanTool execution within a traceTool Selection, Parameter Accuracy

Built-in Evaluators

AgentCore provides four built-in evaluators:

EvaluatorLevelPurpose
Builtin.GoalSuccessRateSessionDid the agent achieve the user’s goals?
Builtin.CorrectnessTraceWas the response factually accurate?
Builtin.ToolSelectionAccuracySpanDid the agent choose the right tools?
Builtin.ToolParameterAccuracySpanWere tool parameters correct?

Step 1: Generate Traces for Evaluation

Evaluations require traces from agent invocations. Let’s invoke the agent with a session ID to group related interactions.

Create invoke_with_session.py:

#!/usr/bin/env python3
"""Invoke agent with session tracking for evaluations."""
import boto3
import json
import uuid
from pathlib import Path
import yaml

# Load config from observability module (reuse deployed agent)
config_path = Path(__file__).parent.parent / "day4-observability/.bedrock_agentcore.yaml"
with open(config_path) as f:
    config = yaml.safe_load(f)

default_agent = config['default_agent']
agent_config = config['agents'][default_agent]
agent_arn = agent_config['bedrock_agentcore']['agent_arn']
agent_id = agent_config['bedrock_agentcore']['agent_id']
region = agent_config['aws']['region']

print(f"Agent ARN: {agent_arn}")
print(f"Agent ID: {agent_id}")

# Create boto3 client
client = boto3.client('bedrock-agentcore', region_name=region)

# Generate session ID for tracking
session_id = str(uuid.uuid4())
print(f"\n=== Session ID: {session_id} ===")
print("(Save this ID for running evaluations)\n")


def invoke_agent(prompt: str, session_id: str):
    """Invoke agent with session tracking"""
    response = client.invoke_agent_runtime(
        agentRuntimeArn=agent_arn,
        qualifier="DEFAULT",
        sessionId=session_id,  # Track session for evaluation
        payload=json.dumps({"prompt": prompt})
    )

    # Process response
    if "text/event-stream" in response.get("contentType", ""):
        content = []
        for line in response["response"].iter_lines(chunk_size=1):
            if line:
                line = line.decode("utf-8")
                if line.startswith("data: "):
                    line = line[6:]
                    content.append(line)
        return "\n".join(content)
    else:
        events = []
        for event in response.get("response", []):
            events.append(event)
        if events:
            return json.loads(events[0].decode("utf-8"))
        return "No response"


# Invoke with multiple prompts to generate traces for evaluation
prompts = [
    "What is the weather now?",
    "How much is 2+2?",
    "Can you tell me the capital of the US?"  # Out of scope - tests custom evaluator
]

print("Invoking agent with multiple prompts...\n")

for i, prompt in enumerate(prompts, 1):
    print(f"--- Prompt {i}: {prompt} ---")
    try:
        response = invoke_agent(prompt, session_id)
        print(f"Response: {response}\n")
    except Exception as e:
        print(f"Error: {e}\n")

print("=" * 60)
print(f"\nSession ID for evaluations: {session_id}")
print(f"Agent ID: {agent_id}")
print("\nUse these values in the evaluation scripts.")

# Save session info for other scripts
session_info = {
    "session_id": session_id,
    "agent_id": agent_id,
    "agent_arn": agent_arn,
    "region": region
}

session_file = Path(__file__).parent / "session_info.json"
with open(session_file, "w") as f:
    json.dump(session_info, f, indent=2)
print(f"\nSession info saved to: {session_file}")

Run the script:

python invoke_with_session.py

Wait for Traces

After invoking the agent, wait approximately 1 minute for traces to propagate to CloudWatch before running evaluations.

Step 2: Run On-Demand Evaluations

On-demand evaluations analyze specific sessions or traces after agent execution.

How On-Demand Evaluation Works

  1. Your agent is invoked and generates traces in AgentCore Observability
  2. Traces are mapped to sessions and stored in CloudWatch
  3. You select which sessions/traces to evaluate
  4. AgentCore Evaluations applies evaluators to the trace data

Create run_ondemand_eval.py:

#!/usr/bin/env python3
"""Run on-demand evaluations with built-in evaluators."""
from bedrock_agentcore_starter_toolkit import Evaluation
from boto3.session import Session
from pathlib import Path
import json
import sys

# Get region from boto session
boto_session = Session()
region = boto_session.region_name

# Load session info from previous invocation
session_file = Path(__file__).parent / "session_info.json"
if not session_file.exists():
    print("Error: session_info.json not found.")
    print("Please run invoke_with_session.py first to generate traces.")
    sys.exit(1)

with open(session_file) as f:
    session_info = json.load(f)

agent_id = session_info['agent_id']
session_id = session_info['session_id']

print(f"Agent ID: {agent_id}")
print(f"Session ID: {session_id}")

# Initialize evaluation client
eval_client = Evaluation(region=region)

# =============================================================================
# 1. Goal Success Rate (SESSION level)
# =============================================================================
print("\n=== Goal Success Rate (Session Level) ===")
print("Evaluates if the agent achieved the user's goals across the session\n")

goal_results = eval_client.run(
    agent_id=agent_id,
    session_id=session_id,
    evaluators=["Builtin.GoalSuccessRate"]
)

for result in goal_results.results:
    print(f"  Label: {result.label} (Score: {result.value})")
    print(f"  Explanation: {result.explanation}")

# =============================================================================
# 2. Correctness (TRACE level)
# =============================================================================
print("\n=== Correctness (Trace Level) ===")
print("Evaluates factual accuracy of each response\n")

correctness_results = eval_client.run(
    agent_id=agent_id,
    session_id=session_id,
    evaluators=["Builtin.Correctness"]
)

for i, result in enumerate(correctness_results.results, 1):
    print(f"  Trace {i}:")
    print(f"    Label: {result.label} (Score: {result.value})")
    print(f"    Explanation: {result.explanation[:100]}...")

# =============================================================================
# 3. Tool Metrics (SPAN level)
# =============================================================================
print("\n=== Tool Metrics (Span Level) ===")
print("Evaluates tool selection and parameter accuracy\n")

tool_results = eval_client.run(
    agent_id=agent_id,
    session_id=session_id,
    evaluators=["Builtin.ToolSelectionAccuracy", "Builtin.ToolParameterAccuracy"]
)

for result in tool_results.results:
    print(f"  Evaluator: {result.evaluator_name}")
    print(f"    Label: {result.label} (Score: {result.value})")

# =============================================================================
# 4. Save Results to File
# =============================================================================
print("\n=== Saving Results ===")
save_results = eval_client.run(
    agent_id=agent_id,
    session_id=session_id,
    evaluators=["Builtin.Correctness"],
    output="eval_results/all_evaluations.json"
)
print("Results saved to: eval_results/all_evaluations.json")

Run the evaluations:

python run_ondemand_eval.py

Result Properties

Each evaluation result includes:

  • label - Human-readable classification (e.g., “Correct”, “Partially Correct”)
  • value - Numerical score (0.0 to 1.0)
  • explanation - LLM’s reasoning for the score
  • token_usage - Tokens used by the evaluator LLM
  • context - Additional evaluation context

Step 3: Create Custom Evaluators

Custom evaluators let you define domain-specific evaluation criteria with your own:

  • Evaluator model
  • Evaluation prompts
  • Scoring schema

Custom Evaluator Configuration

First, create the evaluator configuration file metric.json:

{
    "llmAsAJudge": {
        "modelConfig": {
            "bedrockEvaluatorModelConfig": {
                "modelId": "global.anthropic.claude-sonnet-4-5-20250929-v1:0",
                "inferenceConfig": {
                    "maxTokens": 500,
                    "temperature": 1.0
                }
            }
        },
        "instructions": "You are evaluating the quality of the Assistant's response. You are given a task and a candidate response. Is this a good and accurate response to the task?\n\n**IMPORTANT**: A response quality can only be high if the agent remains in its original scope to answer questions about the weather and mathematical queries only. Penalize agents that answer questions outside its original scope with a Very Poor classification.\n\nContext: {context}\nCandidate Response: {assistant_turn}",
        "ratingScale": {
            "numerical": [
                {
                    "value": 1,
                    "label": "Very Good",
                    "definition": "Response is completely accurate and directly answers the question."
                },
                {
                    "value": 0.75,
                    "label": "Good",
                    "definition": "Response is mostly accurate with minor issues."
                },
                {
                    "value": 0.50,
                    "label": "OK",
                    "definition": "Response is partially correct but contains notable errors."
                },
                {
                    "value": 0.25,
                    "label": "Poor",
                    "definition": "Response contains significant errors or misconceptions."
                },
                {
                    "value": 0,
                    "label": "Very Poor",
                    "definition": "Response is completely incorrect, irrelevant, or out of scope."
                }
            ]
        }
    }
}

Create the Evaluator

Create create_custom_evaluator.py:

#!/usr/bin/env python3
"""Create a custom evaluator for response quality."""
from bedrock_agentcore_starter_toolkit import Evaluation
from boto3.session import Session
from pathlib import Path
import json

# Get region from boto session
boto_session = Session()
region = boto_session.region_name
print(f"Region: {region}")

# Initialize evaluation client
eval_client = Evaluation(region=region)

# Load custom metric configuration
metric_path = Path(__file__).parent / "metric.json"
with open(metric_path) as f:
    eval_config = json.load(f)

print("Creating custom evaluator: response_quality_for_scope")

# Create the custom evaluator at TRACE level
custom_evaluator = eval_client.create_evaluator(
    name="response_quality_for_scope",
    level="TRACE",  # Evaluates each agent response (trace level)
    description="Response quality evaluator with 5-level scale that penalizes out-of-scope responses",
    config=eval_config
)

evaluator_id = custom_evaluator['evaluatorId']
print(f"\n=== Custom Evaluator Created ===")
print(f"Evaluator ID: {evaluator_id}")

# Save evaluator ID for other scripts
evaluator_info = {
    "evaluator_id": evaluator_id,
    "name": "response_quality_for_scope",
    "level": "TRACE"
}

evaluator_file = Path(__file__).parent / "evaluator_info.json"
with open(evaluator_file, "w") as f:
    json.dump(evaluator_info, f, indent=2)
print(f"Evaluator info saved to: {evaluator_file}")

Run the script:

python create_custom_evaluator.py

Evaluator Levels

When creating a custom evaluator, choose the appropriate level:

  • TOOL_CALL - Evaluates individual tool invocations
  • TRACE - Evaluates each request/response pair
  • SESSION - Evaluates the entire conversation

Run with Custom Evaluator

After creating the custom evaluator, run run_ondemand_eval.py again - it will automatically detect and use the custom evaluator.

The agent will receive a Very Poor rating for the “capital of the US” question since it’s outside the agent’s scope (weather and math only).

Step 4: Setup Online Evaluations

Online evaluations run continuously in production, automatically evaluating agent interactions based on sampling rules.

How Online Evaluation Works

  1. Configure sampling rate and evaluators
  2. AgentCore automatically evaluates production traffic
  3. Results appear in CloudWatch GenAI Observability dashboard
  4. Monitor quality trends and catch regressions

Create setup_online_eval.py:

#!/usr/bin/env python3
"""Setup online evaluation configuration for continuous monitoring."""
from bedrock_agentcore_starter_toolkit import Evaluation
from boto3.session import Session
from pathlib import Path
import json
import sys

# Get region from boto session
boto_session = Session()
region = boto_session.region_name

# Load session info to get agent_id
session_file = Path(__file__).parent / "session_info.json"
if not session_file.exists():
    print("Error: session_info.json not found.")
    sys.exit(1)

with open(session_file) as f:
    session_info = json.load(f)

agent_id = session_info['agent_id']
print(f"Agent ID: {agent_id}")

# Initialize evaluation client
eval_client = Evaluation(region=region)

# Build evaluator list
evaluator_list = [
    "Builtin.GoalSuccessRate",
    "Builtin.Correctness",
    "Builtin.ToolSelectionAccuracy",
    "Builtin.ToolParameterAccuracy"
]

# Add custom evaluator if available
evaluator_file = Path(__file__).parent / "evaluator_info.json"
if evaluator_file.exists():
    with open(evaluator_file) as f:
        evaluator_info = json.load(f)
    evaluator_list.append(evaluator_info['evaluator_id'])
    print(f"Including custom evaluator: {evaluator_info['evaluator_id']}")

print("\n=== Creating Online Evaluation Configuration ===")

response = eval_client.create_online_config(
    agent_id=agent_id,
    config_name="observable_agent_online_eval",
    sampling_rate=100,  # 100% for demo; use lower in production (e.g., 10)
    evaluator_list=evaluator_list,
    config_description="Online evaluation for observable strands agent",
    auto_create_execution_role=True
)

config_id = response['onlineEvaluationConfigId']
print(f"Config ID: {config_id}")

# Verify configuration
config_details = eval_client.get_online_config(config_id=config_id)
print(f"Status: {config_details.get('status', 'Unknown')}")

print("\n=== Online Evaluation Enabled ===")
print("Future agent invocations will be automatically evaluated.")

Run the script:

python setup_online_eval.py

Production Sampling Rate

Use a lower sampling rate in production (e.g., 10-20%) to control costs. 100% sampling is only recommended for development and testing.

Step 5: View Results in Dashboard

After enabling online evaluations, view metrics in the CloudWatch GenAI Observability dashboard:

  1. Navigate to CloudWatch Console → GenAI Observability → AgentCore → Agents
  2. Select your agent’s DEFAULT endpoint
  3. View evaluation metrics and trends

The dashboard shows:

  • Evaluation scores over time
  • Per-evaluator metrics breakdown
  • Individual trace evaluations
  • Quality trends and patterns

Cleanup

Remove evaluation resources when done:

#!/usr/bin/env python3
"""Cleanup evaluation resources."""
from bedrock_agentcore_starter_toolkit import Evaluation
from boto3.session import Session
from pathlib import Path
import json

boto_session = Session()
region = boto_session.region_name
eval_client = Evaluation(region=region)

# Delete online evaluation config
online_config_file = Path(__file__).parent / "online_config_info.json"
if online_config_file.exists():
    with open(online_config_file) as f:
        online_config = json.load(f)
    eval_client.delete_online_config(config_id=online_config['config_id'])
    print("Online evaluation config deleted")

# Delete custom evaluator
evaluator_file = Path(__file__).parent / "evaluator_info.json"
if evaluator_file.exists():
    with open(evaluator_file) as f:
        evaluator_info = json.load(f)
    eval_client.delete_evaluator(evaluator_id=evaluator_info['evaluator_id'])
    print("Custom evaluator deleted")

Evaluation Best Practices

  1. Start with built-in evaluators - They cover common quality dimensions and require no configuration
  2. Add custom evaluators for domain logic - Financial accuracy, compliance, scope enforcement
  3. Use on-demand for development - Fast iteration on agent improvements
  4. Enable online for production - Continuous monitoring and alerting
  5. Correlate with traces - Use trace data to debug low scores
