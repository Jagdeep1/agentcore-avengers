# Code Interpreter & Browser

Memory lets your agent remember. Now let's give it the ability to **do** - execute code and analyze data.

- **Browser Tool**: (AWS Console setup required - see callout below)

## How Code Interpreter Works

The code execution sandbox enables agents to safely process user queries by creating an isolated environment with a code interpreter, shell, and file system. After a Large Language Model helps with tool selection, code is executed within this session, before being returned to the user or agent for synthesis.

![Code Interpreter Architecture](/images/day-3/code-interpreter-architecture.png)

**Architecture Components:**
1. **Agent** - Uses LLM to understand user query and generate Python code
2. **Code Interpreter Session** - Isolated sandbox environment for execution
3. **Execution Environment** - Includes Python runtime, file system, pre-installed libraries
4. **Response Stream** - Results returned to agent for synthesis

**Session Configuration:**
- Default timeout: 900 seconds (15 minutes)
- Recommended for analysis: 1200 seconds (20 minutes)
- State persists between executions within same session
- Region: us-west-2 (US West - Oregon)

## Why Code Interpreter?

**Without Code Interpreter:**
```
User: "What's the average of 15.7, 23.4, 18.9, 21.2?"
Agent: "The average is approximately 19.8"  ← May hallucinate
```

**With Code Interpreter:**
```
User: "What's the average of 15.7, 23.4, 18.9, 21.2?"
Agent: *executes Python code*
       >>> numbers = [15.7, 23.4, 18.9, 21.2]
       >>> sum(numbers) / len(numbers)
       19.8
Agent: "The average is exactly 19.8"  ← Computed, not hallucinated
```

## Step 1: Agent with Code Interpreter

Strands agents can use Code Interpreter for accurate calculations and data analysis.

**Create `agent_with_code_interpreter.py`:**

```python
#!/usr/bin/env python3
"""
agent_with_code_interpreter.py - Strands Agent with Code Interpreter

Demonstrates using AgentCore Code Interpreter with a Strands agent
for accurate data analysis and calculations.
"""

import json
from bedrock_agentcore.tools.code_interpreter_client import CodeInterpreter
from strands import Agent, tool
from strands.models import BedrockModel

# Initialize Code Interpreter in us-west-2 (where AgentCore is available)
code_client = CodeInterpreter('us-west-2')
code_client.start(session_timeout_seconds=1200)  # 20 min for analysis tasks

SYSTEM_PROMPT = """You are a data analysis assistant with Python execution capabilities.

VALIDATION PRINCIPLES:
1. Always validate answers through code execution
2. Use execute_python to test calculations and logic
3. Show your work with actual code execution
4. If uncertain, validate what you can

The sandbox maintains state between executions, so you can refer to previous results.

RESPONSE FORMAT: The execute_python tool returns JSON with:
- isError: Boolean indicating if there was an error
- content: Array with execution results
- structuredContent: stdout, stderr, exitCode, executionTime
"""

@tool
def execute_python(code: str, description: str = "") -> str:
    """Execute Python code in the sandbox.

    Args:
        code: Python code to execute
        description: Optional description of what the code does

    Returns:
        JSON response with execution results
    """
    if description:
        code = f"# {description}\n{code}"

    print(f"\nGenerated Code:\n{code}\n")

    response = code_client.invoke("executeCode", {
        "code": code,
        "language": "python",
        "clearContext": False
    })

    for event in response["stream"]:
        return json.dumps(event["result"])

# Use Claude Haiku 4.5 with Cross-region Inference (CRIS)
model = BedrockModel(model_id="global.anthropic.claude-haiku-4-5-20251001-v1:0")

agent = Agent(
    model=model,
    tools=[execute_python],
    system_prompt=SYSTEM_PROMPT
)

try:
    # Example: Simple calculation
    query = "Calculate the average of these numbers: 15.7, 23.4, 18.9, 21.2"

    response = agent(query)
    print(response)

finally:
    # Always stop the session to release resources
    code_client.stop()
    print("\nCode Interpreter session stopped successfully!")
```

**Run the script:**

```bash
python agent_with_code_interpreter.py
```

**Expected output:**

```
Tool #1: execute_python

Generated Code:

numbers = [15.7, 23.4, 18.9, 21.2]
average = sum(numbers) / len(numbers)
print(f"Average: {average}")

The average of these numbers is 19.8.

Code Interpreter session stopped successfully!
```

**What just happened:**
- ✓ Agent wrote Python code to calculate the average
- ✓ Code Interpreter executed code in secure sandbox with 20-minute timeout
- ✓ Result is accurate (computed, not hallucinated)
- ✓ Session was properly cleaned up with `stop()`
- ✓ Uses explicit model ID for Claude Haiku 4.5

## Step 2: Direct Code Interpreter (No Agent)

Use Code Interpreter directly without an agent framework for programmatic control.

**Create `direct_code_interpreter.py`:**

```python
#!/usr/bin/env python3
import json
from bedrock_agentcore.tools.code_interpreter_client import CodeInterpreter

REGION = "us-west-2"

def main():
    # Initialize Code Interpreter client
    code_client = CodeInterpreter(REGION)

    # Start a session with 20-minute timeout for longer analysis tasks
    code_client.start(session_timeout_seconds=1200)

    try:
        # Example 1: Calculate compound interest
        code1 = """
principal = 1000
rate = 0.05
years = 10
final_amount = principal * (1 + rate) ** years
print(f"Final amount: ${final_amount:,.2f}")
"""
        response = code_client.invoke("executeCode", {
            "language": "python",
            "code": code1
        })

        for event in response["stream"]:
            result = event["result"]
            if "content" in result:
                for item in result["content"]:
                    if item["type"] == "text":
                        print(item["text"])

        # Example 2: State persists between executions
        code2 = """
# Reference variables from previous execution
interest = final_amount - principal
print(f"Interest earned: ${interest:,.2f}")
"""
        response = code_client.invoke("executeCode", {
            "language": "python",
            "code": code2
        })

        for event in response["stream"]:
            result = event["result"]
            if "content" in result:
                for item in result["content"]:
                    if item["type"] == "text":
                        print(item["text"])

    finally:
        code_client.stop()

if __name__ == "__main__":
    exit(main())
```

**Run the script:**

```bash
python direct_code_interpreter.py
```

**Expected output:**

```
Final amount: $1,628.89
Interest earned: $628.89
```

**What just happened:**
- ✓ Started Code Interpreter session programmatically
- ✓ Executed code directly (no agent)
- ✓ State persisted between executions (variables retained)
- ✓ Cleaned up session resources

**Use cases for direct usage:**
- Programmatic code execution in scripts
- Integration into existing Python applications
- Fine-grained control over execution
- Batch processing and automation

## Advanced: File Operations

Code Interpreter can work with files in the sandbox environment.

**Example: Upload and analyze CSV data:**

```python
# Upload file to sandbox
csv_content = """name,age,score
Alice,25,95
Bob,30,87
Charlie,22,92"""

files_to_create = [{
    "path": "data.csv",
    "text": csv_content
}]

# Write files to sandbox
response = code_client.invoke("writeFiles", {"content": files_to_create})

# List files to verify
result = code_client.invoke("listFiles", {"path": ""})
for event in result["stream"]:
    print(json.dumps(event["result"], indent=2))

# Analyze the uploaded file
code = """
import pandas as pd
df = pd.read_csv('data.csv')
print(df.describe())
"""
response = code_client.invoke("executeCode", {
    "code": code,
    "language": "python"
})

for event in response["stream"]:
    result = event["result"]
    if "content" in result:
        for item in result["content"]:
            if item["type"] == "text":
                print(item["text"])
```

**File Operations Available:**
- `writeFiles`: Upload files to sandbox
- `listFiles`: List files in sandbox directory
- `readFiles`: Read file contents from sandbox
- `deleteFiles`: Remove files from sandbox

<Callout type="tip" title="S3 Integration">
Code Interpreter can access files from S3 buckets, enabling analysis of large datasets without API size limitations.
</Callout>

## AgentCore Browser Tool

Browser tool enables web automation - navigating sites, extracting data, filling forms, and capturing screenshots.

### How Browser Tool Works

The Browser tool provides these capabilities:

- **Navigate websites**: Visit URLs and interact with pages
- **Extract information**: Get text content, HTML, and links
- **Form automation**: Fill forms and click buttons
- **Screenshots**: Capture page visuals for verification
- **JavaScript execution**: Run custom scripts on pages

### Step 3: Agent with Browser Tool

Strands agents can use Browser tool for intelligent web automation using the `strands_tools.browser.AgentCoreBrowser` integration.

**Install browser tool dependencies:**

```bash
pip install strands-agents-tools playwright>=1.40.0 requests>=2.31.0 websockets>=11.0.0
playwright install chromium
```

**Create `agent_with_browser.py`:**

```python
#!/usr/bin/env python3
"""
agent_with_browser.py - Strands Agent with Browser Tool

Demonstrates using AgentCore Browser tool with a Strands agent
for intelligent web automation and data extraction.
"""

import time
from strands import Agent
from strands_tools.browser import AgentCoreBrowser

# Initialize the AgentCoreBrowser tool
agent_core_browser = AgentCoreBrowser(region="us-east-1")

SYSTEM_PROMPT = """You are an intelligent web analyst that specializes in browsing and analyzing websites.

When asked to analyze a website:
1. Use the browser tool to visit and interact with the website EFFICIENTLY
2. Focus on extracting key information QUICKLY
3. Work efficiently and complete your analysis within 2-3 browser interactions
4. Always provide specific insights with actual data points
5. Be concise but comprehensive in your analysis
"""

# Create agent with Claude Haiku model
agent = Agent(
    tools=[agent_core_browser.browser],
    model="global.anthropic.claude-haiku-4-5-20251001-v1:0",
    system_prompt=SYSTEM_PROMPT
)

def analyze_website(url: str, question: str = None) -> str:
    """Analyze a website and extract information.

    Args:
        url: Website URL to analyze
        question: Optional specific question to answer

    Returns:
        Analysis results as string
    """
    if question:
        prompt = f"Visit {url} and answer this question: {question}"
    else:
        prompt = f"Please analyze the website at {url} and provide key insights"

    try:
        print(f"🚀 Starting analysis of {url}...")
        start_time = time.time()

        response = agent(prompt)

        elapsed_time = time.time() - start_time
        print(f"✅ Analysis completed in {elapsed_time:.2f} seconds")

        # Extract text from response
        if response.message.get("content"):
            return response.message["content"][0]["text"]
        return str(response)

    except Exception as e:
        print(f"❌ Error during analysis: {str(e)}")
        return f"Error occurred: {str(e)}"

if __name__ == "__main__":
    # Example: Analyze Hacker News (reliable site without bot protection)
    result = analyze_website(
        "https://news.ycombinator.com",
        "What are the top 3 stories on the front page?"
    )
    print(result)
```

**Run the script:**

```bash
python agent_with_browser.py
```

**Expected output:**

```
🚀 Starting analysis of https://news.ycombinator.com...
Tool #1: browser
Tool #2: browser
✅ Analysis completed in 20.06 seconds

Here are the **top 3 stories on Hacker News front page**:

1. **"Story Title 1"** - Brief description of the first story
2. **"Story Title 2"** - Brief description of the second story
3. **"Story Title 3"** - Brief description of the third story
```

**What just happened:**
- ✓ Agent navigated to Hacker News using Browser tool
- ✓ Extracted story titles and descriptions from the page
- ✓ AI processed and summarized the information
- ✓ Uses headless browser automation (no console setup required)

<Callout type="info" title="Browser Tool Performance">
Browser tool operations typically complete in 10-20 seconds depending on website complexity. The tool handles JavaScript-rendered pages and can extract data from dynamic content.
</Callout>

<Callout type="warning" title="Bot Protection">
Some websites (like MarketWatch, Bloomberg) have anti-bot protection (captcha) that may block automated access. If you encounter captcha issues, try alternative data sources or consider using APIs for financial data.
</Callout>
