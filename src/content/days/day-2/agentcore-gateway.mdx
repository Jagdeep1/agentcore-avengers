# AgentCore Gateway

Your agent is authenticated. Now it needs to **do things** - access APIs, retrieve data, trigger actions. AgentCore Gateway provides a unified, secure interface for connecting your agent to the tools and services it needs.

## Why Gateway?

Without Gateway, connecting agents to tools is painful:

```
❌ Without Gateway:
- Each API requires custom integration code
- Credential management spread across your codebase
- No standard protocol for tool discovery
- Security is your responsibility
```

Gateway transforms this:

```
✅ With Gateway:
- Unified MCP interface for all tools
- Centralized, secure credential management
- Semantic search for intelligent tool discovery
- Built-in authentication and authorization
```

<Callout type="info" title="MCP: Model Context Protocol">
  Gateway speaks MCP - an open protocol designed for LLM-tool communication.
  This means your agent can discover and use tools without custom integration code.
</Callout>

## Gateway Target Types

AgentCore Gateway supports six target types to connect your agent to different services:

| Target Type | Use Case | Description |
|-------------|----------|-------------|
| **OpenAPI Schema** | Transform REST APIs | Upload OpenAPI spec (JSON/YAML), Gateway auto-generates MCP tools from API operations |
| **AWS Lambda** | Custom business logic | Connect Lambda functions as MCP tools for custom processing |
| **API Gateway REST API** | Existing AWS APIs | Integrate existing Amazon API Gateway REST API stages as targets |
| **Smithy Model** | AWS-style APIs | Use Smithy models to define API schemas for tool generation |
| **MCP Servers** | Existing MCP servers | Route requests to existing MCP-compliant servers |
| **Built-in Integrations** | Popular services | Pre-built templates for Slack, GitHub, Salesforce, Jira, etc. |

### When to Use Each Target Type

- **OpenAPI Schema**: You have an existing REST API with OpenAPI documentation
- **AWS Lambda**: You need custom business logic or want to wrap internal services
- **API Gateway REST API**: You already have APIs deployed in Amazon API Gateway
- **Smithy Model**: You're building AWS-style APIs or prefer Smithy's type system
- **MCP Servers**: You have existing MCP-compliant tool servers to integrate
- **Built-in Integrations**: Quick integration with popular SaaS services (no custom code needed)

<Callout type="info" title="Tutorial Focus">
  In this tutorial, we'll focus on the **OpenAPI Schema target** pattern as it's the most common way to transform existing REST APIs into MCP tools. The other target types follow similar patterns for Gateway creation and authentication.
</Callout>

### Step 2: Create IAM Role for Gateway

Create `setup_gateway_role.py` to create an IAM role that the Gateway will assume:

```python
# setup_gateway_role.py - Create IAM role for Gateway
import boto3
import json

iam_client = boto3.client('iam')
sts_client = boto3.client('sts')

ROLE_NAME = "agentcore-gateway-role"

# Get account ID
account_id = sts_client.get_caller_identity()["Account"]

print(f"Creating Gateway IAM role: {ROLE_NAME}")

# Trust policy - allows AgentCore Gateway to assume this role
trust_policy = {
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Principal": {
                "Service": "bedrock-agentcore.amazonaws.com"
            },
            "Action": "sts:AssumeRole",
            "Condition": {
                "StringEquals": {
                    "aws:SourceAccount": account_id
                }
            }
        }
    ]
}

# Create the IAM role
try:
    role_response = iam_client.create_role(
        RoleName=ROLE_NAME,
        AssumeRolePolicyDocument=json.dumps(trust_policy),
        Description="IAM role for AgentCore Gateway"
    )
    role_arn = role_response['Role']['Arn']
    print(f"✅ Created role: {role_arn}")
except iam_client.exceptions.EntityAlreadyExistsException:
    role_arn = f"arn:aws:iam::{account_id}:role/{ROLE_NAME}"
    print(f"ℹ️  Role already exists: {role_arn}")

# Attach Gateway permissions (includes credential provider access)
gateway_policy = {
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "bedrock-agentcore:*",
                "bedrock:*",
                "agent-credential-provider:*",
                "iam:PassRole",
                "secretsmanager:GetSecretValue",
                "lambda:InvokeFunction",
                "s3:GetObject"
            ],
            "Resource": "*"
        }
    ]
}

iam_client.put_role_policy(
    RoleName=ROLE_NAME,
    PolicyName="GatewayPermissions",
    PolicyDocument=json.dumps(gateway_policy)
)
print("✅ Attached Gateway permissions")

print(f"\n📝 Save this for later steps:")
print(f"   GATEWAY_ROLE_ARN = \"{role_arn}\"")
```

### Step 3: Set Up Cognito for Inbound Auth

Create `setup_cognito.py` to set up Cognito for Gateway inbound authentication:

```python
# setup_cognito.py - Set up Cognito for Gateway inbound auth
import boto3
import os

REGION = os.environ.get('AWS_DEFAULT_REGION', 'us-east-1')
USER_POOL_NAME = "gateway-auth-pool"
RESOURCE_SERVER_ID = "gateway-resource-server"
CLIENT_NAME = "gateway-client"

cognito = boto3.client("cognito-idp", region_name=REGION)

print("Setting up Cognito for Gateway authentication...")

# Create User Pool
try:
    pool_response = cognito.create_user_pool(PoolName=USER_POOL_NAME)
    user_pool_id = pool_response['UserPool']['Id']
    print(f"✅ Created User Pool: {user_pool_id}")
except Exception as e:
    # Find existing pool
    pools = cognito.list_user_pools(MaxResults=60)['UserPools']
    user_pool_id = next((p['Id'] for p in pools if p['Name'] == USER_POOL_NAME), None)
    print(f"ℹ️  Using existing User Pool: {user_pool_id}")

# Create Resource Server with scopes
SCOPES = [
    {"ScopeName": "gateway:read", "ScopeDescription": "Read access"},
    {"ScopeName": "gateway:write", "ScopeDescription": "Write access"}
]

try:
    cognito.create_resource_server(
        UserPoolId=user_pool_id,
        Identifier=RESOURCE_SERVER_ID,
        Name=RESOURCE_SERVER_ID,
        Scopes=SCOPES
    )
    print("✅ Created Resource Server")
except cognito.exceptions.InvalidParameterException:
    print("ℹ️  Resource Server already exists")

# Create App Client for M2M auth
try:
    client_response = cognito.create_user_pool_client(
        UserPoolId=user_pool_id,
        ClientName=CLIENT_NAME,
        GenerateSecret=True,
        AllowedOAuthFlows=['client_credentials'],
        AllowedOAuthScopes=[
            f"{RESOURCE_SERVER_ID}/gateway:read",
            f"{RESOURCE_SERVER_ID}/gateway:write"
        ],
        AllowedOAuthFlowsUserPoolClient=True
    )
    client_id = client_response['UserPoolClient']['ClientId']
    client_secret = client_response['UserPoolClient']['ClientSecret']
    print(f"✅ Created App Client: {client_id}")
except Exception as e:
    print(f"Error creating client: {e}")
    raise

# Create domain for token endpoint
domain_prefix = f"gateway-{user_pool_id.split('_')[1].lower()}"
try:
    cognito.create_user_pool_domain(
        Domain=domain_prefix,
        UserPoolId=user_pool_id
    )
    print(f"✅ Created domain: {domain_prefix}")
except cognito.exceptions.InvalidParameterException:
    print(f"ℹ️  Domain already exists: {domain_prefix}")

# Discovery URL for Gateway
discovery_url = f"https://cognito-idp.{REGION}.amazonaws.com/{user_pool_id}/.well-known/openid-configuration"
token_url = f"https://{domain_prefix}.auth.{REGION}.amazoncognito.com/oauth2/token"

print(f"\n📝 Save these values for later steps:")
print(f"   USER_POOL_ID = \"{user_pool_id}\"")
print(f"   CLIENT_ID = \"{client_id}\"")
print(f"   CLIENT_SECRET = \"{client_secret}\"")
print(f"   DISCOVERY_URL = \"{discovery_url}\"")
print(f"   TOKEN_URL = \"{token_url}\"")
print(f"   SCOPES = \"{RESOURCE_SERVER_ID}/gateway:read {RESOURCE_SERVER_ID}/gateway:write\"")
```

# create_gateway.py - Create Gateway with JWT authorizer
import boto3
import os

REGION = os.environ.get('AWS_DEFAULT_REGION', 'us-east-1')

# Replace with values from previous steps
GATEWAY_ROLE_ARN = "arn:aws:iam::123456789012:role/agentcore-gateway-role"
CLIENT_ID = "your-client-id"
DISCOVERY_URL = "https://cognito-idp.us-east-1.amazonaws.com/us-east-1_xxxxxx/.well-known/openid-configuration"

gateway_client = boto3.client('bedrock-agentcore-control', region_name=REGION)

print("Creating AgentCore Gateway...")

# JWT authorizer configuration (security built-in)
auth_config = {
    "customJWTAuthorizer": {
        "allowedClients": [CLIENT_ID],
        "discoveryUrl": DISCOVERY_URL
    }
}

create_response = gateway_client.create_gateway(
    name='MarsWeatherGateway',
    roleArn=GATEWAY_ROLE_ARN,
    protocolType='MCP',
    authorizerType='CUSTOM_JWT',
    authorizerConfiguration=auth_config,
    description='AgentCore Gateway for NASA Mars Weather API'
)

gateway_id = create_response["gatewayId"]
gateway_url = create_response["gatewayUrl"]

print(f"✅ Gateway created!")
print(f"   Gateway ID: {gateway_id}")
print(f"   Gateway URL: {gateway_url}")

print(f"\n📝 Save these values for later steps:")
print(f"   GATEWAY_ID = \"{gateway_id}\"")
print(f"   GATEWAY_URL = \"{gateway_url}\"")

```python
# upload_openapi_spec.py - Upload OpenAPI spec to S3
import boto3
import os

session = boto3.session.Session()
s3_client = session.client('s3')
sts_client = session.client('sts')

# Get account info
account_id = sts_client.get_caller_identity()["Account"]
region = session.region_name

# Create bucket name
bucket_name = f'agentcore-gateway-{account_id}-{region}'
file_path = 'nasa_mars_insights_openapi.json'
object_key = 'nasa_mars_insights_openapi.json'

print(f"Uploading OpenAPI spec to S3...")

# Create bucket if it doesn't exist
try:
    if region == "us-east-1":
        s3_client.create_bucket(Bucket=bucket_name)
    else:
        s3_client.create_bucket(
            Bucket=bucket_name,
            CreateBucketConfiguration={'LocationConstraint': region}
        )
    print(f"✅ Created bucket: {bucket_name}")
except s3_client.exceptions.BucketAlreadyOwnedByYou:
    print(f"ℹ️  Bucket already exists: {bucket_name}")

# Upload the OpenAPI spec
with open(file_path, 'rb') as file_data:
    s3_client.put_object(
        Bucket=bucket_name,
        Key=object_key,
        Body=file_data
    )

openapi_s3_uri = f's3://{bucket_name}/{object_key}'
print(f"✅ Uploaded OpenAPI spec!")
print(f"   S3 URI: {openapi_s3_uri}")

print(f"\n📝 Save this for the next step:")
print(f"   OPENAPI_S3_URI = \"{openapi_s3_uri}\"")
```

### Step 8: Create Agent with Gateway Tools

Create `get_token.py` to get an access token from Cognito:

```python
# get_token.py - Get access token from Cognito
import requests
import base64

# Replace with your Cognito values
CLIENT_ID = "your-client-id"
CLIENT_SECRET = "your-client-secret"
TOKEN_URL = "https://gateway-xxxxxx.auth.us-east-1.amazoncognito.com/oauth2/token"
SCOPES = "gateway-resource-server/gateway:read gateway-resource-server/gateway:write"

def get_access_token():
    """Get M2M access token from Cognito."""
    credentials = base64.b64encode(f"{CLIENT_ID}:{CLIENT_SECRET}".encode()).decode()

    response = requests.post(
        TOKEN_URL,
        headers={
            "Authorization": f"Basic {credentials}",
            "Content-Type": "application/x-www-form-urlencoded"
        },
        data={
            "grant_type": "client_credentials",
            "scope": SCOPES
        }
    )

    if response.status_code == 200:
        return response.json()["access_token"]
    else:
        raise Exception(f"Failed to get token: {response.text}")

if __name__ == "__main__":
    token = get_access_token()
    print(f"✅ Got access token!")
    print(f"   Token: {token[:50]}...")
```

Create `agent_gateway.py` to create an agent using Gateway MCP tools:

```python
# agent_gateway.py - Agent using Gateway MCP tools
from strands.models import BedrockModel
from mcp.client.streamable_http import streamablehttp_client
from strands.tools.mcp.mcp_client import MCPClient
from strands import Agent
import logging

# Replace with your values
GATEWAY_URL = "https://xxxxxxxxxx.bedrock-agentcore-gateway.us-east-1.amazonaws.com"
TARGET_NAME = "NasaMarsWeatherTarget"

# Import token helper
from get_token import get_access_token

# Configure logging
logging.getLogger("strands").setLevel(logging.INFO)
logging.basicConfig(
    format="%(levelname)s | %(name)s | %(message)s",
    handlers=[logging.StreamHandler()]
)

print("🚀 Starting Mars Weather Agent...")

# Get access token for Gateway
print("Getting access token...")
token = get_access_token()
print("✅ Got access token!")

# Create MCP client to connect to Gateway
def create_streamable_http_transport():
    return streamablehttp_client(
        GATEWAY_URL,
        headers={"Authorization": f"Bearer {token}"}
    )

client = MCPClient(create_streamable_http_transport)

# Initialize the model
model = BedrockModel(
    model_id="us.amazon.nova-pro-v1:0",
    temperature=0.7
)

# Use the MCP client with the agent
with client:
    # List available tools from Gateway
    tools = client.list_tools_sync()
    print(f"✅ Tools loaded: {[t.tool_name for t in tools]}")

    # Create agent with Gateway tools
    agent = Agent(
        model=model,
        tools=tools,
        system_prompt="You are a Mars Weather assistant. Use the available tools to get weather data from Mars."
    )

    # Test the agent
    print("\n🔴 Asking about Mars weather...")
    response = agent("What is the weather on Mars?")
    print(f"\n✅ Response: {response.message['content'][0]['text']}")

    # You can also call the tool directly
    print("\n📡 Calling tool directly...")
    result = client.call_tool_sync(
        tool_use_id="get-mars-weather-1",
        name=f"{TARGET_NAME}___getInsightWeather",
        arguments={"ver": "1.0", "feedtype": "json"}
    )
    print(f"✅ Tool result: {result['content'][0]['text'][:200]}...")
```

cognito = boto3.client('cognito-idp', region_name=REGION)

print("🧹 Cleaning up resources...")

# Delete Gateway
try:
    gateway_client.delete_gateway(gatewayId=GATEWAY_ID)
    print(f"✅ Deleted Gateway: {GATEWAY_ID}")
except Exception as e:
    print(f"❌ Error deleting Gateway: {e}")

# Delete Cognito User Pool
try:
    # First delete the domain
    pool_desc = cognito.describe_user_pool(UserPoolId=USER_POOL_ID)
    domain = pool_desc.get('UserPool', {}).get('Domain')
    if domain:
        cognito.delete_user_pool_domain(Domain=domain, UserPoolId=USER_POOL_ID)
        print(f"✅ Deleted Cognito domain: {domain}")

    cognito.delete_user_pool(UserPoolId=USER_POOL_ID)
    print(f"✅ Deleted Cognito User Pool: {USER_POOL_ID}")
except Exception as e:
    print(f"❌ Error deleting Cognito: {e}")

print("\n📝 Also remember to manually delete:")
print("   - IAM role: agentcore-gateway-role")
print("   - S3 bucket: agentcore-gateway-*")
print("   - Credential provider: NasaInsightAPIKey")

## Semantic Tool Search

Gateway enables intelligent tool discovery using semantic search:

```python
# Search for relevant tools based on natural language
search_results = gateway_client.search_tools(
    gatewayId=GATEWAY_ID,
    query="get weather data from Mars",
    maxResults=5
)

for tool in search_results['tools']:
    print(f"Tool: {tool['name']}")
    print(f"  Description: {tool['description']}")
    print(f"  Relevance: {tool['relevanceScore']}")
```

Your agent can use semantic search dynamically to find the best tool for a task:

```python
@tool
def find_and_use_tool(task_description: str) -> str:
    """Find and execute the most appropriate tool for a task.

    Args:
        task_description: What the user wants to accomplish

    Returns:
        Result of the tool execution
    """
    # Search for relevant tools
    results = gateway_mcp.search_tools(task_description)

    if not results:
        return "No suitable tool found for this task"

    best_tool = results[0]
    return f"Found tool: {best_tool.name} - {best_tool.description}"
```

## Monitoring and Debugging

### CloudWatch Metrics

Gateway provides detailed metrics in CloudWatch:

```bash
# View Gateway metrics
aws cloudwatch get-metric-statistics \
  --namespace AWS/BedrockAgentCoreGateway \
  --metric-name ToolInvocations \
  --dimensions Name=GatewayId,Value=gw-xxxx \
  --start-time 2025-01-03T00:00:00Z \
  --end-time 2025-01-03T23:59:59Z \
  --period 3600 \
  --statistics Sum
```

Key metrics to monitor:

| Metric | Description |
|--------|-------------|
| `ToolInvocations` | Total number of tool calls |
| `ToolLatency` | Response time for tool calls |
| `ToolErrors` | Number of failed invocations |
| `AuthorizationFailures` | Authentication/authorization failures |

### Request Tracing

Enable tracing for debugging:

```python
# Invoke with tracing enabled
response = gateway_mcp.invoke_tool(
    tool_name='getInsightWeather',
    arguments={'ver': '1.0', 'feedtype': 'json'},
    trace=True
)

print(f"Trace ID: {response.trace_id}")
# View traces in CloudWatch: /aws/bedrock-agentcore-gateway/traces
```
